# VTK Website

Welcome to the VTK Website repository! This project contains the source code and assets for the official website of the [Visualization Toolkit (VTK)](https://vtk.org/). **NOT YET PUBLISHED**

## Overview

This repository powers the public-facing website for VTK, an open-source software system for 3D computer graphics, image processing, and visualization. The website provides documentation, downloads, community resources, and news about VTK.

## Features

- Project documentation and guides
- Download links for VTK releases
- Community and support resources
- News and updates about VTK

## Getting Started

1. **Clone the repository:**
    ```sh
    git clone https://github.com/Kitware/vtk-website.git
    cd vtk-website
    ```

2. **Install dependencies:**  
    (See `CONTRIBUTING.md` or project-specific instructions.)

3. **Run the development server:**  
    `npm run dev`
