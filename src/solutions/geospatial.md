# Geospatial

VTK supports geospatial visualization for GIS, terrain rendering, and earth science applications.

## Capabilities

- **Terrain visualization** — Elevation maps and terrain rendering
- **Map projections** — Geographic coordinate system transformations
- **GIS data support** — GeoJSON, shapefiles, and raster data
- **LiDAR point clouds** — LAS/LAZ format support
- **Globe rendering** — 3D Earth visualization
- **Satellite imagery** — Drape imagery over terrain models

## Data Sources

- Digital elevation models (DEM)
- GeoTIFF raster data
- Vector data (shapefiles, GeoJSON)
- Point cloud data (LAS/LAZ)
- NetCDF climate and weather data

## Applications

- Climate and weather visualization
- Oceanographic data analysis
- Geological modeling
- Urban planning
- Environmental monitoring
- Natural disaster assessment
