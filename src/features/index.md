# Features

VTK provides a comprehensive set of capabilities for scientific visualization, data processing, and 3D graphics.

## Core Capabilities

VTK's feature set spans the full visualization pipeline — from data ingestion and processing to rendering and interaction.

- [**Data Model**](/features/data-model) — Flexible data structures for grids, meshes, images, and more
- [**Filters**](/features/filters) — 200+ processing filters with a pipeline architecture
- [**Rendering**](/features/rendering) — 3D rendering, volume rendering, and ray tracing
- [**Interaction**](/features/interaction) — Widgets, picking, and interactor styles
- [**Charts**](/features/charts) — 2D plotting and charting
- [**Parallel Processing**](/features/parallel) — MPI and multi-threading support
- [**I/O Formats**](/features/io) — 50+ supported file formats

## Why VTK?

- **Battle-tested** — Over 30 years of development and real-world use
- **Comprehensive** — One toolkit covers the entire visualization workflow
- **Multi-language** — Native C++ with Python and JavaScript bindings
- **Cross-platform** — Linux, macOS, and Windows
- **Open source** — BSD-licensed, free for any use
