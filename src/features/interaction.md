# Interaction

VTK provides tools for interactive exploration and manipulation of 3D data.

## 3D Widgets

- **Box widget** — Define a bounding box for clipping or region selection
- **Plane widget** — Position a cutting plane interactively
- **Sphere widget** — Spherical region selection
- **Line widget** — Define lines and curves in 3D
- **Spline widget** — Create smooth curves through control points
- **Handle widgets** — Drag points in 3D space

## Picking

- Cell and point picking
- Hardware-accelerated picking
- Rubber-band selection (area picking)
- Prop picking for selecting actors

## Interactor Styles

- **Trackball camera** — Intuitive camera rotation, zoom, and pan
- **Joystick** — Continuous camera motion
- **Flight** — Fly-through navigation
- **Image** — 2D image viewing (pan and zoom)
- **Custom styles** — Create your own interaction paradigms

## Integration

- Qt integration for desktop applications
- Trame integration for web applications
- Callback system for custom event handling
