# Rendering

VTK provides a comprehensive rendering system for creating high-quality visualizations of scientific data.

## 3D Surface Rendering

- OpenGL-based rendering with hardware acceleration
- Physically-based rendering (PBR) materials
- Transparency and depth peeling
- Ambient occlusion and shadows
- Texture mapping and environment mapping

## Volume Rendering

- GPU-accelerated ray casting
- Multi-volume rendering
- Transfer function editors for opacity and color
- Support for large volumetric datasets
- Independent component rendering

## Ray Tracing

- Integration with Intel OSPRay for high-fidelity rendering
- Path tracing for photorealistic images
- Global illumination
- Ambient occlusion
- Denoising for interactive exploration

## Additional Capabilities

- **Offscreen rendering** — Generate images without a display
- **Stereo rendering** — Support for 3D displays and VR headsets
- **Large-scale rendering** — Parallel rendering with sort-last compositing
- **Export** — Save to images (PNG, JPEG, TIFF), PDF, and GL2PS vector formats
