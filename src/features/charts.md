# 2D Charts and Plotting

VTK includes a charting framework for creating publication-quality 2D plots and graphs.

## Supported Chart Types

- **Line plots** — Time series, function plots, parametric curves
- **Scatter plots** — Point distributions with configurable markers
- **Bar charts** — Vertical and horizontal bar charts
- **Stacked plots** — Stacked bar and area charts
- **Box plots** — Statistical distribution visualization
- **Pie charts** — Proportional data display
- **Parallel coordinates** — Multi-dimensional data exploration
- **Bag plots** — 2D statistical plots

## Features

- Configurable axes with linear and logarithmic scales
- Legends and annotations
- Interactive zooming and panning
- Mouse-over tooltips
- Multiple plots in a single view
- Export to vector and raster formats

## Integration

- Embed charts alongside 3D visualizations
- Data-driven updates from VTK data arrays
- Context-based rendering for high-quality output
