# The VTK Textbook

*The Visualization Toolkit: An Object-Oriented Approach to 3D Graphics* is the definitive reference for VTK.

## About the Book

Written by Will Schroeder, Ken Martin, and Bill Lorensen (the creators of VTK), this textbook covers both the theory and practice of 3D computer graphics and visualization.

The book is available online at [book.vtk.org](https://book.vtk.org).

## Contents

The textbook covers:

- Computer graphics fundamentals
- Visualization algorithms and techniques
- The VTK object model and architecture
- Volume rendering
- Image processing
- Interaction and widgets
- Practical examples with complete source code
