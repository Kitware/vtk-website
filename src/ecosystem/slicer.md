# 3D Slicer

[3D Slicer](https://www.slicer.org/) is a free, open-source platform for medical image informatics, image processing, and 3D visualization built on VTK.

## Overview

3D Slicer provides a comprehensive environment for medical image computing. It is widely used in clinical research, pre-surgical planning, and medical education. Slicer uses VTK for all its 3D rendering and data processing.

## Key Features

- **Multi-modality support** — CT, MRI, PET, ultrasound, and more
- **Segmentation** — Manual and semi-automatic segmentation tools
- **Registration** — Image alignment and atlas-based registration
- **DICOM support** — Full DICOM reading, writing, and networking
- **3D printing** — Export segmented models for 3D printing
- **Extensions** — Rich ecosystem of community extensions
- **Python scripting** — Automate workflows and create custom modules

## Use Cases

- Surgical planning and navigation
- Radiation therapy planning
- Neuroimaging research
- Cardiac imaging
- Orthopedic analysis
- Veterinary medicine
