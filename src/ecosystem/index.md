# Ecosystem

VTK is the foundation for a rich ecosystem of visualization tools and frameworks. These projects extend VTK's capabilities for specific domains and use cases.

## Key Projects

- [**ParaView**](/ecosystem/paraview) — Desktop and web-based data analysis and visualization application
- [**Trame**](/ecosystem/trame) — Python framework for building interactive web visualization applications
- [**PyVista**](/ecosystem/pyvista) — Pythonic interface to VTK for 3D plotting and mesh analysis
- [**vtk.js**](/ecosystem/vtk-js) — JavaScript implementation of VTK for web browsers
- [**3D Slicer**](/ecosystem/slicer) — Medical imaging platform for visualization and analysis
