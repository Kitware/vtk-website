# vtk.js

[vtk.js](https://kitware.github.io/vtk-js/) is a JavaScript implementation of VTK for rendering scientific data in web browsers.

## Overview

vtk.js brings VTK's visualization capabilities to the web using WebGL. It implements a subset of VTK's functionality in pure JavaScript, enabling client-side 3D visualization without plugins or server-side rendering.

## Key Features

- **WebGL rendering** — Hardware-accelerated 3D graphics in the browser
- **VTK-compatible** — Familiar API for VTK users
- **File format support** — Read VTK, VTP, STL, OBJ, and other formats
- **Widgets** — Interactive 3D manipulation tools
- **Volume rendering** — GPU-accelerated volume visualization
- **React and Vue integration** — Components for modern web frameworks

## Getting Started

```bash
npm install @kitware/vtk.js
```
