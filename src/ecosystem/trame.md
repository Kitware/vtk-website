# Trame

[Trame](https://trame.readthedocs.io/) is a Python framework for building interactive visualization web applications using VTK.

## Overview

Trame makes it easy to create web-based visualization applications with just Python. It bridges VTK's powerful visualization engine with modern web technologies, enabling both server-side and client-side rendering.

## Key Features

- **Pure Python** — Build web apps without JavaScript
- **Server or client rendering** — Choose the best approach for your data
- **Component library** — Pre-built UI components for common visualization tasks
- **Reactive state** — Automatic UI updates when data changes
- **Deployment flexibility** — Run locally, on a server, or in the cloud
- **Jupyter integration** — Use Trame widgets in notebooks

## Getting Started

```bash
pip install trame trame-vtk trame-vuetify
```
