# VTK Logo

Official VTK logos for use in presentations, publications, and websites.

## Usage Guidelines

- Use the official logos without modification
- Maintain the aspect ratio when resizing
- Ensure adequate spacing around the logo
- Do not alter the colors or proportions

## Available Formats

*Logo downloads will be available here in the following formats:*

- **SVG** — Scalable vector format for web and print
- **PNG** — High-resolution raster format with transparent background
- **PDF** — Vector format for print publications
