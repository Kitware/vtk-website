# Contributing to VTK

VTK welcomes contributions from the community. Here's how to get involved.

## Ways to Contribute

- **Report bugs** — File issues on [VTK GitLab](https://gitlab.kitware.com/vtk/vtk/-/issues)
- **Fix bugs** — Submit merge requests for bug fixes
- **Add features** — Implement new algorithms or capabilities
- **Improve documentation** — Fix errors, add examples, clarify descriptions
- **Write examples** — Contribute to [VTK Examples](https://examples.vtk.org)
- **Help others** — Answer questions on [Discourse](https://discourse.vtk.org)

## Development Workflow

1. Fork the repository on GitLab
2. Create a topic branch for your changes
3. Follow VTK coding style and conventions
4. Write tests for new functionality
5. Submit a merge request
6. Participate in code review

## Coding Standards

- Follow existing VTK coding style
- Use VTK naming conventions (vtkClassName, SetProperty/GetProperty)
- Document public APIs
- Include unit tests for new code

## Contributor License Agreement

Contributors may need to sign a Contributor License Agreement (CLA) before their contributions can be merged.
