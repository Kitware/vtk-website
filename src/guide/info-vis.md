# Information Visualization

VTK's capabilities for visualizing abstract, non-spatial data.

## Charts and Plots

- Line charts, scatter plots, bar charts
- Box plots, pie charts
- Stacked and grouped charts
- Interactive chart features (zoom, selection, tooltips)

## Graph and Network Visualization

- Graph layout algorithms (force-directed, tree, hierarchical)
- Edge bundling for complex networks
- Interactive graph exploration
- Graph analysis integration

## Tree and Hierarchical Data

- Treemap visualization
- Sunburst diagrams
- Tree layout algorithms
- Hierarchical data structures (vtkTree)

## Tabular Data

- Table-based data model (vtkTable)
- Parallel coordinates for multi-dimensional exploration
- Linked views — Coordinate multiple visualizations

## Topics Covered

- Creating publication-quality charts
- Interacting with chart elements
- Combining information visualization with 3D views
- Custom chart types and annotations
