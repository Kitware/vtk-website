# Geospatial Visualization

Working with geographic and terrain data in VTK.

## Coordinate Systems

- Geographic coordinate systems (latitude/longitude)
- Projected coordinate systems
- Coordinate transformations between systems
- vtkGeoTransform and projection support

## Terrain Visualization

- Digital elevation models (DEM)
- Terrain rendering with texture draping
- Contour lines on terrain
- Profile extraction

## Vector Data

- GeoJSON reader and visualization
- Point, line, and polygon features
- Attribute-based styling
- Label placement

## Raster Data

- GeoTIFF support
- Satellite imagery overlay
- Multi-band raster visualization
- Elevation data processing

## Topics Covered

- Loading and displaying geographic data
- Combining raster and vector layers
- Map projections and coordinate transformations
- LiDAR point cloud visualization
- Climate and weather data on geographic grids
