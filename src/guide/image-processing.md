# Image Processing

VTK's image processing capabilities for 2D and 3D image data.

## Image Data in VTK

- vtkImageData structure and organization
- Pixel types and data ranges
- Image coordinate systems (origin, spacing, extent)
- Multi-component images

## Basic Operations

- Arithmetic operations (add, subtract, multiply)
- Thresholding and segmentation
- Histogram computation and equalization
- Windowing and leveling for display

## Filtering

- Gaussian smoothing and noise reduction
- Edge detection (Sobel, Canny)
- Morphological operations (erosion, dilation, opening, closing)
- Convolution with custom kernels
- Median filtering

## Advanced Operations

- Image registration and resampling
- Connected component labeling
- Distance transforms
- Fourier transforms and frequency domain filtering

## Topics Covered

- Working with medical image data (DICOM)
- Multi-planar reformatting (MPR)
- Image interpolation methods
- Batch processing of image stacks
