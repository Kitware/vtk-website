# VTK User's Guide

The VTK User's Guide provides comprehensive documentation for learning and using the Visualization Toolkit.

## Chapters

1. [**Installation**](/guide/installation) — Installing VTK on your system
2. [**System Overview**](/guide/system-overview) — Architecture, object model, and design patterns
3. [**The Basics**](/guide/basics) — Fundamental concepts: pipeline, data model, rendering
4. [**Visualization Techniques**](/guide/visualization) — Scalar, vector, and tensor visualization
5. [**Image Processing**](/guide/image-processing) — 2D and 3D image processing operations
6. [**Volume Rendering**](/guide/volume-rendering) — Direct volume rendering techniques
7. [**Information Visualization**](/guide/info-vis) — Charts, graphs, and abstract data visualization
8. [**Geospatial Visualization**](/guide/geospatial) — Geographic and terrain data
9. [**Building Models**](/guide/building-models) — Constructing geometric models programmatically
10. [**Time-Varying Data**](/guide/time-varying) — Temporal data handling and animation
11. [**Reading & Writing Data**](/guide/reading-writing) — File formats and I/O
12. [**Interaction & Widgets**](/guide/interaction) — User interaction, 3D widgets, and selections
