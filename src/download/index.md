# Download VTK

Get VTK for your platform and preferred language.

## Python (Recommended)

The easiest way to install VTK:

```bash
pip install vtk
```

Pre-built wheels are available for:
- Linux (x86_64, aarch64)
- macOS (x86_64, arm64)
- Windows (x86_64)
- Python 3.9 — 3.12

## Source Code

### Latest Release

Download the latest VTK release from the [VTK releases page](https://vtk.org/download/).

### Git Repository

```bash
git clone https://gitlab.kitware.com/vtk/vtk.git
```

See [Building from Source](/docs/building) for compilation instructions.

## System Packages

VTK is available through many system package managers:

- **Ubuntu/Debian**: `apt install libvtk9-dev python3-vtk9`
- **macOS (Homebrew)**: `brew install vtk`
- **Windows (vcpkg)**: `vcpkg install vtk`

## Release Archive

Previous VTK releases are available on the [VTK download page](https://vtk.org/download/).
