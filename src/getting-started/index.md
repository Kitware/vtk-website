# Getting Started

Choose your preferred language or framework to start using VTK.

## By Language

- [**Python**](/getting-started/python) — The fastest way to get started. Install with pip and start visualizing in minutes.
- [**C++**](/getting-started/cpp) — Native performance with CMake-based builds.
- [**JavaScript**](/getting-started/javascript) — Visualization in the browser with vtk.js or WebAssembly.

## By Framework

- [**Frameworks**](/getting-started/frameworks) — Use VTK through higher-level tools like ParaView, Trame, or PyVista.

## Which approach is right for me?

| Approach | Best For |
|----------|----------|
| **Python** | Rapid prototyping, data analysis, scripting |
| **C++** | Performance-critical applications, embedding VTK |
| **JavaScript** | Web-based visualization |
| **ParaView** | Interactive exploration without coding |
| **Trame** | Building web applications with Python |
| **PyVista** | Pythonic 3D plotting, NumPy workflows |
