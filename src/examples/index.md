# Examples

VTK has an extensive collection of examples demonstrating its capabilities across C++, Python, and other languages.

## VTK Examples Website

Browse the full collection at [**examples.vtk.org**](https://examples.vtk.org).

The examples site includes:

- **Searchable index** — Find examples by class name, technique, or keyword
- **C++ examples** — Complete, compilable programs
- **Python examples** — Ready-to-run Python scripts
- **Categorized browsing** — Examples organized by topic

## Example Categories

- **Geometry** — Creating and manipulating geometric shapes
- **Visualization** — Color mapping, contouring, streamlines, glyphs
- **Volume rendering** — Transfer functions, GPU ray casting
- **Image processing** — Filtering, segmentation, display
- **Interaction** — Widgets, picking, custom interactors
- **I/O** — Reading and writing data files
- **Rendering** — Lighting, textures, transparency, PBR

## Contributing Examples

New examples are always welcome. See the [contributing guide](https://examples.vtk.org/site/VTKContributing/) for instructions.
