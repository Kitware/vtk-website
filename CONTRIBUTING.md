# Contributing to VTK Website

You are welcome to contribute to the VTK Website! Whether it's fixing bugs, adding new features, or improving documentation, your contributions are valuable to us. You will need an environment with Node.js and npm installed to run and test the website locally.

## Install Node.js

If you do not already have Node.js installed, please download and install it from [nodejs.org](https://nodejs.org/en/download).

## How to Contribute

1. Clone the repository:
    ```sh
    git clone https://github.com/Kitware/vtk-website.git
    cd vtk-website
    ```
2. Install dependencies:
    ```sh
    npm install
    ```
3. Run the development server:
    ```sh
    npm run dev
    ```
4. Make your changes and test them locally.
5. Commit your changes and push to your forked repository.
6. Open a pull request against the `main` branch of this repository.
7. For pull requests from branches in this repository, a bot comments with a link to a preview of the built site. The link updates with each push and expires after 7 days without one. Pull requests from forks don't get a preview.

For major changes, please open an issue first to discuss your proposed changes with the maintainers.
